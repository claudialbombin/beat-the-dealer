Estimates

Backward induction

After you hit, the rest of the hand must be played well too. The solver handles states in an order where everything a hit can lead to is already solved (hard 21→11, soft 21→12, hard 10→4), so the continuation always uses the best policy found so far. The original version of this project continued with "hit until 17", which systematically undervalued hitting.

Common random numbers

With the toggle on, every action faces the same dealer hand and the same next cards. The noise that both estimates share cancels in their difference, so the right action is identified with far fewer hands. Turn it off and watch the “hands needed” figure jump.

How many hands is enough?

The standard error falls as 1/√N: 100× more hands buys 10× more precision. Cells where two actions differ by less than 0.1% of a bet need millions of hands each, which is why the published solver uses 2,000,000 hands per action.
